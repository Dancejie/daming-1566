# 大明1566 · 无雪之冬

原著开篇的互动改编。新章从嘉靖三十九年冬的言祸与财政困境，进入四十年正月的御前议财，结束于改稻为桑开始向浙江传达。六场、51 个正文节点、四种文书结果。玩家是第一人称随堂书办，选择改变记录和责任，不提前扭转原作的大事件。

## 运行与版本

根目录 `python server.py` 同时运行三个版本：

- `/original/`：本章，内容版本 2.0.0，独立 SQLite 与 `echo.ming1566.original.v2` 本机存档。
- `/storm/`：原“风暴初夜”，内容和原本机存档保持可用。
- `/classic/`：最初的人物对话名场面。

根网址跳转本章。人物图继续由既有 `/assets/` 提供；书办采用第一人称手部镜头，不使用旧模板中不符合书办设定的金衣人物图。六位原人物及表情资源保留。胡宗宪和海瑞本章尚未会面。

共同使用原有 Engine：选择/自由进言确认/QTE → 状态结算；演出、跳过、重播不产生结算。服务器遗失临时 SQLite 后，可由浏览器的完整动作记录重建。两章不互相导入存档。

## 制作

`production/` 保存原著出处、完整交互文本、逐秒导演稿和每片 prompt。最新婉儿对照资料区分已制作第一、二集与尚属导演稿的第四集。全片请求 exact `seedance-2.5`，不降级；付费请求与账户凭据只保存在本地制作项目，不进入部署包。

媒体只有完成技术、动作和音频检查后，才列入 `media/runtime-manifest.json` 的 ready 清单。原生中文对白和环境音，播放器加载独立 VTT 字幕。四条章末片只在对应选择已确认后播放。
